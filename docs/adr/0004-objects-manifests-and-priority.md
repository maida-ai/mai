# Current manifests and leases

Current manifests and ordinary leases use file units. mai computes manifests from Git changes; agent declarations do not replace that evidence. Lease commands require the exact current generation claim. Leases coordinate trusted local work and are not operating-system permissions.

Semantic-object units, differentiated priority, preemption and automated recovery are not current behavior. See [receive and integration](../receive.md) and [current delivery and limits](../release-status.md).
