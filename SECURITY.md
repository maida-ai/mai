# Security reporting

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/maida-ai/mai/security/advisories/new). Include the version, a minimal reproduction and impact; do not put credentials, raw agent context or private source in a public issue.

mai 0.0.x is experimental software for trusted local evaluation. Worktrees are not sandboxes, agent names are not authenticated identities, and ordinary Git access can bypass current publication controls. See [current limitations](docs/release-status.md). No supported production release or response-time guarantee is declared.
